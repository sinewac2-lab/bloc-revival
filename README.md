# Nation Sim Game — Bloc Revival

A Bloc-style Cold War nation simulation. Create and lead your own nation: economy, military, diplomacy, alliances, spies and nukes.

Play it live (once GitHub Pages is switched on): https://sinewac2-lab.github.io/bloc-revival/

Your game saves automatically in your own browser (local storage) on the device you play on — each player gets their own separate nation and save.
